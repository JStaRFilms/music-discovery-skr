## Indexing (measured)

Model: `laion/larger_clap_music` at revision
`a0b4534a14f58e20944452dff00a22a06ce629d1`. Five sparse 10-second windows
per track, mono 48 kHz decoded through FFmpeg.

- Smoke run, 5 tracks: 25 windows in 5.46 s, 4.58 windows/s on CUDA.
  That figure includes model load.
- Full run, remaining 35 tracks: 175 windows in 31.73 s, 5.52 windows/s.
- Total: 200 windows for 40 tracks. Resuming correctly embedded 0 new
  windows for the five smoke tracks.
- Full-library projection from the measured rate, arithmetic only:
  1,510 tracks at five windows is about 7,550 windows, roughly 23 minutes
  at 5.5 windows/s before decode variance. This is a projection from a
  40-track sample, not a measured full run.

Failure found and fixed in this run: Transformers 5.21 returns
`BaseModelOutputWithPooling` from CLAP feature calls instead of a bare
tensor. The first smoke attempt crashed with `AttributeError` on
`.detach`. `features_to_numpy` in `src/music_discovery/embed.py` now
unwraps `pooler_output`, with regression tests in `tests/test_embed.py`.
